# 🚢 Titanic Data Analysis and Visualization Using Python

## 📌 Project Overview

This project focuses on analyzing and visualizing Titanic passenger data using Python.

The project uses Pandas for data manipulation and Matplotlib for data visualization. It explores passenger demographics, embarkation locations, age distribution, and survival statistics.

## 🚀 Features

- Load Titanic passenger data from an Excel file.
- Handle missing values in the dataset.
- Display the first 10 rows of passenger data.
- Analyze male and female passenger distribution.
- Visualize passenger embarkation locations.
- Explore passenger age distribution.
- Analyze passenger survival statistics.
- Generate four visualizations in a single dashboard.
- Save the visualization dashboard as a high-resolution PNG image.

## 📊 Data Visualizations

The project generates four charts:

### 1. Gender Distribution
A bar chart displaying the distribution of male and female passengers.

### 2. Embarkation Distribution
A pie chart representing passenger embarkation locations.

### 3. Age Distribution
A histogram exploring passenger age values.

### 4. Survival Distribution
A pie chart showing the proportion of passengers who survived and did not survive.
